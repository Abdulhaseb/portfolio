How I work

Five stages of an implementation

  1. 1

    Requirement workshops

    Walk through each department's process and record the gaps against standard Odoo.

  2. 2

    Configuration

    Set up companies, modules and workflows, using standard features first.

  3. 3

    Customization and reports

    Close the remaining gaps with Studio, QWeb and automated actions.

  4. 4

    Data migration and testing

    Import masters and opening balances, then test full cycles with the client.

  5. 5

    Training and go-live

    Train each team on its own role and stay close through the first weeks.

Standard first
